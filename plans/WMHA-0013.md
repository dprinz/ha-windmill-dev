# Plan for WMHA-0013

## Current state verified

- `custom_components/windmill/strings.json` and `custom_components/windmill/translations/en.json`
  are byte-identical and already complete in English: config steps `user`, `workspace`,
  `capabilities`, `features`, `reauth_confirm`, `reconfigure`, errors, aborts, all entity keys
  (`database`, `instance_health`, `alive_workers`, `pending_jobs`, `running_jobs`,
  `worker_group_alive`, `worker_group_versions`, `worker_instance_alive`, `workspace_running_jobs`,
  `workspace_queued_jobs`, `last_successful_run`, `last_failed_run`, event `run`, button
  `run_runnable`, update `server`), options steps `init`/`features`/`runnables`, services `run` and
  `cancel`, 21 exception keys and the three `issues` keys from WMHA-0012
  (`missing_permission`, `unsupported_capability`, `worker_version_drift`).
- `custom_components/windmill/translations/de.json` does not exist; German is entirely missing.
- `scripts/validate_repository.py` checks required files, ticket frontmatter and local Markdown
  links, but nothing about translation keys. No translation coverage check exists anywhere
  (grep over `tests/` finds only `translation_key` usage in behavior tests).
- The root `README.md` still claims production code is not implemented; there is no user
  documentation. `manifest.json` points `documentation` at the repository root, so the README is
  the user-documentation location.
- Actions are exactly `windmill.run` and `windmill.cancel` (`services.py`, `services.yaml`);
  entity translation keys are as listed above; repair issues are the three keys above
  (`issues.py`).
- Worker lifecycle facts to document come from ADR-0002; the orphaned-store note from WMHA-0020.

## Failure modes and rollback

- German text drifting from the English meaning — mitigated by translating key for key against
  `en.json`; rollback is deleting `de.json`.
- The new validation check producing false positives on nested structures — flattening is a plain
  recursive dict walk over string leaves, same shape for all three files; rollback is removing the
  function.
- README documenting names that do not exist — every name is copied from source, not paraphrased.

## Security and privacy review

  `<token>`) and explicitly says never to publish tokens.
- Sensitive payloads: the safe automation examples use fake paths and job IDs.
- Permissions: the permission matrix documents existing least-privilege behavior; nothing changes.
- Network exposure: none.
