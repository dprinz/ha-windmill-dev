## Failure modes and rollback

- Gate failure — fix only gate-relevant defects; anything else becomes a backlog ticket. All changes here are docs/tests, so rollback is `git checkout`.
- Docker unavailable or Windmill CE fails to start within a bounded attempt — stop, document exactly what was tried, record missing live coverage as release risk; do not fake E2E.
- Smoke test leaves state — compose project with explicit name; `docker compose down -v` plus image removal afterwards.

## Security and privacy review

- Credentials: only a freshly generated throwaway superadmin secret/token for the local disposable instance; never committed; never a production system.
- Sensitive payloads: smoke test scripts take no arguments and return trivial data; no real payloads retained.
- Permissions: least privilege where cheap (workspace token); superadmin only for instance bootstrap of the disposable container.
- Network exposure: instance bound to localhost; torn down afterwards.
