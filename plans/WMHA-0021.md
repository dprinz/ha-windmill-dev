# Plan for WMHA-0021

## Current state verified

- `custom_components/windmill/sensor.py:54` (`_worker_sensors`) builds group and instance entities
  once from the first snapshot; nothing adds or removes worker entities later.
- `custom_components/windmill/__init__.py` reads the configured worker groups once through
  `_async_configured_worker_groups(client)` and passes them as `known_groups`.
- `WindmillWorkerInstanceSensor.native_value` returns `instances.get(subject, 0)`, so a silent
  instance reports `0` rather than disappearing; `WindmillWorkerGroupSensor` does the same for a
  configured but idle group.
- `tests/test_workers.py` covered the pre-seeded groups and the anti-churn goal, but neither the
  `0` state of a fully silent instance nor the reload requirement for a new instance.

## Failure modes and rollback

- Documenting behavior the code does not have — mitigated by pinning both documented consequences
  with tests. Rollback is deleting the ADR and the two tests; no production code changes.

## Security and privacy review

- Credentials: none.
- Sensitive payloads: the ADR names no host, only the shape of the identifier; the tests use the
  existing fake `host1`/`host9` fixtures.
- Permissions: unchanged.
- Network exposure: one documentation fetch of an already registered public source.

## Open questions

- ADR versus scoped documentation: an ADR, because the decision constrains every future worker or
  entity-lifecycle ticket and the review of `WMHA-0006` could not tell the trade-off from an
  oversight. Scoped documentation would not have been found by the next agent.
- Ephemeral `worker_instance`: unconfirmed. The Windmill worker-group documentation checked on
  2026-08-02 documents `WORKER_GROUP` but says nothing about how `worker_instance` is derived, so
  the ADR records it as an explicitly unvalidated risk instead of a confirmed defect.

## Plan changes

The ticket allowed a documentation-only change. Two tests were added anyway, because the ticket also
requires that documentation must not imply behavior the code does not have, and neither documented
consequence had a test.
